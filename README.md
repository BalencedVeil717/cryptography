# Cryptography

This repository contains code to implement different types of cipher and decipher methods in using JAVA.

---

### 1. Caesar Cipher

The Caesar cipher is a monoalphabetic substitution cipher that transforms a message by shifting its letters by a given
offset. First used by Julius Caesar.

### 2. Atbash Cipher

The Atbash cipher is a monoalphabetic substitution cipher that maps each letter of an alphabet to its reverse
counterpart.
Originally used with the Hebrew alphabet.

### 3. ROT13 / ROT47

The ROT13 cipher is a monoalphabetic substitution cipher that replaces each letter with the one 13 positions later in
the Latin alphabet, making it easily reversible. Popular in the 1980s to hide jokes, spoilers, etc.

The ROT47 cipher is a monoalphabetic substitution cipher that shifts each of the 94 printable ASCII characters (from !
to ~) forward by 47 positions, making encryption and decryption the same operation.
