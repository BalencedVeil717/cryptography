# Cryptography

This repository contains code to implement different types of cipher and decipher methods in using JAVA.

---

### 1. Caesar Cipher

The Caesar cipher is a monoalphabetic substitution cipher that transforms a message by shifting its letters by a given
offset. First used by Julius Caesar.

### 2. Atbash Cipher

The Atbash cipher is a monoalphabetic substitution cipher that maps each letter of an alphabet to its reverse counterpart.
Originally used with the Hebrew alphabet.
